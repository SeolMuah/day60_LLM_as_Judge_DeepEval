# 캐릭터 삽화 이미지 프롬프트

도식(흐름도·표·비교 그림)은 `scripts/diagrams/`의 HTML로 직접 렌더링합니다. 이 파일에는 **캐릭터가 나오는 삽화**만 남깁니다. ChatGPT Images 등에서 **기존 이미지를 첨부해 고치는 방식**으로 쓰면 그림체가 그대로 유지됩니다.

**공통 스타일:** 기존 그림과 같은 친근한 교육용 플랫 일러스트(둥근 굵은 외곽선, 파스텔 칸, 남색 제목 띠·글자 띠, 흰 글씨), 16:9, 1600x900. 판사 모델은 "검은 법복에 칩 배지를 단 캐릭터"입니다. 일차·Day 번호는 넣지 않고, 프롬프트에 적은 문구 외의 글자는 넣지 않습니다.

**본문과 같은 용어:** 사람 판정, 판사 판정, 기준 답변, 테스트 케이스, 평가 범위표, 판사 성적표.

## 1. 00_lesson02_goals.png (필수)

기존 `images/00_lesson02_goals.png`를 첨부하고 아래 프롬프트를 씁니다.

```
첨부한 이미지를 그대로 유지하고 ④번 칸의 아래 남색 글자 띠의 문구만 바꿔 주세요.
- 바꿀 문구(두 줄): "평가 범위표로" / "테스트 케이스 설계"
- 기존 문구 "커버리지 표로 테스트 케이스 설계"는 지웁니다.
나머지(제목, ①~③ 칸, 그림, 색, 글자 크기·굵기·위치)는 바꾸지 마세요.
글자 크기와 굵기는 다른 칸의 띠 글자와 같게 맞추고, 위 문구 외의 글자는 넣지 마세요.
16:9, 1600x900.
```

```

1) ①번 칸: 책상 오른쪽의 빨강·노랑·초록 줄무늬 카드를 지우고,

   판사가 답안지에 초록 체크 도장을 찍는 모습은 그대로 둡니다.

2) ③번 칸: 그림은 그대로 두고 아래 남색 글자 띠 문구만 두 줄로 바꿉니다.

나머지 칸(②, ④)과 제목 "오늘 배울 것: 판사 모델로 채점하고 판사를 검증하기"는 바꾸지 마세요.
```
