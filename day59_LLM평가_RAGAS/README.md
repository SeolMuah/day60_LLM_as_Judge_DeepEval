## 설치와 설정

ragas 0.4.3은 langchain-community 0.4.2에서 import가 실패합니다. **이 단원을 시작하기 전에** `실습자료` 폴더에서 아래 파일로 설치합니다. 앞 단원의 requirements(예: day54)를 다시 설치하면 langchain-community가 0.4.2로 돌아가므로, 그 뒤에는 이 명령을 한 번 더 실행합니다.

```bash
uv pip install -r day59_LLM평가_RAGAS/requirements-day59.txt
```

앞 단원의 OpenAI 설정을 재사용합니다. 상위 `실습자료/.env`에 이미 있는 값은 다시 적지 않아도 됩니다. 평가용 LLM은 코드 기본값이 `gpt-6-luna`라 적지 않아도 되고, 바꿀 때는 상위 `.env`가 아니라 이 단원 폴더의 `.env`에 적습니다. 상위 `.env`에 적으면 다른 단원의 평가용 LLM 기본값까지 그 값으로 바뀝니다.

```dotenv
OPENAI_API_KEY=발급받은_키
OPENAI_CHAT_MODEL=gpt-5.6-luna
OPENAI_EVAL_MODEL=gpt-6-luna
RAGAS_DO_NOT_TRACK=true
```

- `OPENAI_EVAL_MODEL`: ragas 0.4.3은 `gpt-5.6-luna`처럼 버전에 소수점이 든 이름을 추론(reasoning) 모델로 알아보지 못해 맞지 않는 요청 인자를 보내고, API가 그 요청을 거절합니다. `gpt-6-luna`는 ragas가 추론 모델로 알아보므로 문제없이 쓸 수 있습니다. `gpt-4o-mini`는 검색 문서를 거의 모두 쓸모 있다고 판정해 Context Precision이 순서 차이를 보여 주지 못했기 때문에 기본값에서 뺐습니다.
- `RAGAS_DO_NOT_TRACK`: ragas가 익명 사용 통계를 외부 서버로 보내지 않게 합니다. 노트북의 평가용 LLM 준비 셀에서도 이 전송을 끕니다.

## 진행

- [실습 가이드](실습_가이드.md)에서 진행 순서를 확인합니다.
- 교안마다 새 커널에서 시작합니다. 정답은 `정답/` 폴더를 작업 위치로 하는 커널에서 실행합니다.
- 본실습 코드는 학생본도 완성되어 있어 그대로 실행합니다. 작성 셀(`...`)은 교안 끝의 함께 따라하기 절에만 있고, 완성 코드는 정답본의 같은 절에 있습니다.
- 평가 셀은 평가용 LLM을 실제로 호출합니다. 두 교안 모두 `ascore` 작업을 동시에 실행하며, 동시 실행 상한은 `MAX_CONCURRENCY = 32`입니다. 429 오류나 NaN 점수가 늘어나면 이 값을 줄입니다. 교안 02 정답본은 함께 따라하기를 포함해 통실행에 약 4분 걸렸습니다(분당 요청 5,000회·토큰 200만 한도의 키).
- 셀이 네트워크 오류로 멈추면 그 셀만 다시 실행합니다. 결과 목록은 셀 안에서 새로 만들므로 중복되지 않습니다.
