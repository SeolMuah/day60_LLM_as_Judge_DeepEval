## 3. 교안 파일 순서

**판정: 01 생성 지표 → 02 검색 지표·진단 순서를 유지합니다.**

- 02의 동기 문장("원인이 검색에 있는지 답변 생성에 있는지는 답변 점수만으로 가려낼 수 없습니다")은 답변 지표를 먼저 배워야 성립합니다. 증상(답변)에서 원인(검색)으로 거슬러 가는 진단 흐름입니다.
- 커리큘럼도 개요·분류·Hallucination·Faithfulness를 먼저 둡니다. Faithfulness는 53일차 Self-RAG의 근거성 판정에서 바로 이어집니다.
- 01은 JSON 답변만 평가하므로 준비가 가볍습니다. 검색 지표를 먼저 하면 두 교안 모두 RAG 파이프라인을 세워야 합니다.
- RAGAS 문서가 검색 지표를 먼저 나열하는 것은 참고 순서일 뿐, 교수 순서의 근거는 아닙니다.
- 02 §6-1에서 Faithfulness를 다시 재는 것은 다시 가르치는 것이 아니라 진단에 쓰는 재사용이므로 유지합니다.

**확인 결과 맞는 것**(손댈 필요 없음)
- Faithfulness는 호출 2번이고, 뒷받침된 주장 ÷ 전체 주장입니다. 주장이 없으면 NaN입니다.
- Answer Relevancy는 `strictness=3`이고 코사인 유사도 평균입니다. 세 번 모두 회피성으로 표시되거나 질문을 만들지 못하면 0입니다.
- Answer Correctness는 가중치 0.75/0.25이고, F1 = TP ÷ (TP + 0.5 × (FP + FN))이며, LLM 3번·임베딩 2번을 호출합니다.
- Context Precision은 순위 가중 평균 정밀도이고 문서마다 1번 호출합니다. 0.58, 0.83, 0.5, 0.33, 0.82 계산이 모두 맞습니다.
- Context Recall은 문서를 이어 붙여 1번 호출하고 순위 가중치가 없습니다.
- Context Relevance는 서로 다른 지시문으로 0·1·2점을 두 번 매겨 평균합니다.
- `ragas.metrics.collections`, `ascore`, `.value`, `llm_factory`, `system_prompt`, `max_tokens` 기본 1024, temperature 0.01이 모두 소스와 맞습니다.
- 교안이 적은 호출 수(12, 144, 78, 24, 48, 56)가 모두 코드와 맞습니다.
- 버전: ragas 0.4.3(2026-01-13)이 지금도 최신입니다. langchain-community 0.4.2 import 문제(이슈 #2995)도 아직 열려 있어 `requirements-day59.txt`의 0.4.1 고정이 계속 필요합니다.
