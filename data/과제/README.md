# 과제 데이터: 파이썬 퀴즈 답안과 교사 판정

과제 01(`과제_01_퀴즈_자동_채점_판사_점검.ipynb`)과 과제 02(`과제_02_퀴즈_자동_채점_DeepEval_테스트.ipynb`)가 함께 읽는 자료입니다. 부트캠프 주간 파이썬 퀴즈라는 수업용 가정이며, 학생 답안은 채점 연습을 위해 사람이 쓴 통제 입력입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `python_quiz_set.json` | 문항 6개, 학생 답안 36개와 교사 판정, 채점 규칙, 서술형 쌍 6개, 평가 범위 목표 |

## 구성 (`python_quiz_set.json`)

| 키 | 내용 |
|---|---|
| `items` | 단답 K1(값이 없음을 뜻하는 상수)·K2(키워드)·K3(예외 이름), 서술 E1(리스트와 튜플)·E2(for와 while)·E3(try/except). 문항마다 `question`, 기준 답변 `reference`, 서술형은 채점 항목 `rubric`(A·B) |
| `items[].answers` | 문항마다 답안 유형 6개. `answer_id`(예: `K2-표기_다름`), `answer_type`, `answer`, 교사 판정 `teacher`(pass·fail), `teacher_reason`. 서술형은 항목별 충족 여부 `criteria`(A·B) |
| `grading_rules` | 교사가 쓴 채점 규칙. 단답·서술마다 기준 문장 `criterion`과 판단 단계 `steps` |
| `pair_rule`, `pairs` | 서술형 두 답안 비교 규칙과 쌍 PE1–PE6(문항마다 "길이만 다름"·"긴 오답"), 교사 승자 |
| `answer_types` | 답안 유형의 뜻(단답 6종·서술 6종) |
| `coverage_targets` | 평가 범위표에서 확인할 답안 유형 목록. 지금 답안에 없는 유형이 다음에 더할 후보 |

## 교사 채점 규칙

- **단답:** 덧붙인 설명은 맞든 틀리든 채점하지 않습니다. 띄어쓰기·조사·한글 소리 표기·오류 메시지 표기는 같은 답입니다. 파이썬 이름이라 대소문자가 다르면 다른 답입니다. 답을 둘 이상 나열하거나 상위 개념·다른 언어의 이름을 쓰면 오답입니다.
- **서술:** 채점 항목 A·B를 모두 충족해야 pass입니다. 든 예가 틀리거나 항목과 어긋나는 문장이 하나라도 있으면 그 항목은 미충족입니다. 길이·문체·맞춤법은 보지 않습니다.
- **경계 답안:** 판사가 헷갈리기 쉬운 답(틀린 설명이 붙은 정답, 대소문자만 다른 이름, 숨은 오개념, 틀린 예시, 서툰 표현의 정답, 길지만 B가 빠진 답)을 일부러 넣었습니다.
- 문항마다 pass 3·fail 3, 전체 pass 18·fail 18입니다. 늘 pass만 주는 판사는 일치율 0.5, 실패 탐지율 0이 됩니다.

## 검사

`python scripts/check_quiz_set.py`로 API 없이 검사합니다. 판정 수, 답안 ID 형식, 서술형 A·B와 교사 판정의 일치, 쌍 승자 규칙, 평가 범위 목표를 확인합니다.
